# Sastra — User Guide

The user guide now lives in one place: the per-topic markdown files under
[`content/help/`](./content/help). That single source of truth powers both:

- the in-app **Help** page (sidebar ▸ **Help**), where the same content is
  rendered with search and a table of contents, and
- the in-app **assistant**, which answers "how do I…" questions from these docs
  (and tells you when something isn't a feature).

To read or edit the guide, open the files in [`content/help/`](./content/help) —
each file is one topic (getting started, projects, tasks, rights, budget, print
runs, standups, and so on). When you add or change a feature, update the matching
file so the Help page and the assistant stay accurate. See
[`.claude/rules/help-docs.md`](./.claude/rules/help-docs.md) for the upkeep rule.

> For installing and deploying the app, see [`DEPLOY.md`](./DEPLOY.md). For the
> email setup, see [`EMAILSERVICE.md`](./EMAILSERVICE.md).
