# Getting help

- **Using Sastra:** the in-app **Help** page covers every feature, and the
  assistant answers how-to questions from the same documentation.
- **Self-hosting questions:** start with `docs/self-hosting/`. Then use
  [GitHub Discussions](https://github.com/Sastra-Cloud/sastra/discussions).
- **Bugs:** open a [GitHub issue](https://github.com/Sastra-Cloud/sastra/issues)
  using the bug template. Include the version from `GET /api/version`.
- **Security problems:** `SECURITY.md`.
- **Sastra Cloud customers:** open **Help → Support and feature requests** or
  [the account portal](https://account.sastra.cloud/support). Priority handling
  has no guaranteed response time or feature delivery date. Approved email
  replies continue existing requests; unsolicited email does not create tickets.

Self-hosted installations are supported on a best-effort basis by the
community and the maintainers. There is no SLA.

Private support is available only when an installation is explicitly enrolled.
Self-hosting does not register an installation or send diagnostics to Sastra Cloud.
The AGPL source obligations apply independently of paid hosting or support.
Security reporting commitments remain in [SECURITY.md](SECURITY.md).
